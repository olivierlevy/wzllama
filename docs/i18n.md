# Internationalisation (i18n)

## Vue d'ensemble

wzllama supporte le français et l'anglais avec un système d'i18n basé sur des fichiers JSON.

## Structure des fichiers

```
config/i18n/
├── fr.json    # Français (référence)
└── en.json    # Anglais (à créer)

~/.wzllama/i18n/    # Overlay utilisateur (optionnel)
```

## Format du fichier i18n

### Structure JSON

```json
{
  "_language": {
    "code": "fr",
    "name": "Français",
    "name_en": "French",
    "direction": "ltr"
  },
  
  "menu.main.title": "Menu Principal",
  "menu.main.models": "🤖 Choisir un modèle IA",
  
  "config.performance": "⚡ Performance",
  
  "tool.ollama.description": "Chat avec un modèle IA local"
}
```

## Chargement des traductions

### Chemin de recherche

1. `~/.wzllama/i18n/{lang}.json` - Overlay utilisateur
2. `config/i18n/{lang}.json` - Embarqué dans le binaire
3. `fr.json` fallback si langue non trouvée

### Code de chargement

```rust
// src/config/i18n.rs

    // Recherche dans l'ordre:

    // 3. ~/.wzllama/i18n/fr.json (fallback)
    // 4. config/i18n/fr.json (embedded fallback)

```

## Utilisation dans le code

### Méthodes I18n

```rust
impl I18n {
    /// Traduction simple
    pub fn t(&self, key: &str) -> String {
        self.map.get(key).cloned().unwrap_or_else(|| key.to_string())
    }
    
    /// Traduction avec variables
    pub fn t_with_vars(&self, key: &str, vars: &[(&str, &str)]) -> String {
        let mut text = self.t(key);
        for (var, value) in vars {
            text = text.replace(&format!("{{{}}}", var), value);
        }
        text
    }
}
```

### Exemples d'utilisation

```rust
// Simple
display::header(&i18n.t("menu.main.title"));

// Avec variables
display::warning(&i18n.t_with_vars("config.model_not_found", &[
    ("usage", "code"),
    ("model", &model_name)
]));

// Prompt menu
let choice = Select::new()
    .with_prompt(i18n.t("menu.main.choose"))
    .items(&items)
    .interact()?;
```

## Détection de la langue

### Priorité

1. `~/.wzllama/state.json` - `language` field
2. Variables système: `LANG`, `LANGUAGE`, `LC_ALL`, `LC_MESSAGES`
3. `fr` par défaut

### Code de détection

```rust
pub fn detect_system_language() -> String {
    for var in &["LANG", "LANGUAGE", "LC_ALL", "LC_MESSAGES"] {
        if let Ok(lang) = std::env::var(var) {
            let code = lang.split('.').next().unwrap_or("fr")
                .split('_').next().unwrap_or("fr").to_lowercase();
            if paths::i18n_dir().join(format!("{}.json", code)).exists() {
                return code;
            }
        }
    }
    "fr".to_string()
}
```

## Ajouter une nouvelle langue

### Étapes

1. Copier `config/i18n/fr.json` vers `config/i18n/{lang}.json`
2. Traduire toutes les valeurs
3. Mettre à jour `_language.code` et `_language.name`
4. Tester avec `wzllama check-i18n`

### Validation

```bash
# Vérifier l'intégrité
wzllama check-i18n

# Sortie:
# ⚠️  es : X clés manquantes
```

## Overlay utilisateur

Les utilisateurs peuvent personnaliser les traductions en créant:

```
~/.wzllama/i18n/custom.json
```

Ce fichier remplacera les clés existantes du fichier de langue principal.
